# UltraSaveSkill
Claude Code Skill｜手机电脑双端自适应 · 极致省Token技能

> 一个轻量化Skill，开启后自动压缩输出冗余内容，减少token消耗，适配手机窄屏、电脑宽屏阅读。

## ✨ 功能
- 自动剔除废话、客套话、冗余解释
- 双端自适应排版，手机不挤、电脑规范
- 代码精简，一键复制可用
- 休眠机制：不输入触发指令，不占用上下文
- 适合API中转、服务器部署、代码编写、运维调试

## 📌 触发命令
`/ultra`
`/save`
`/min`
`/lowtoken`
